# Variable: InheritColor

> `const` **InheritColor**: `object`

Defined in: src/FactionMachine/Futuristic/Gag/GagMetal.ts:21

The colour keys the metal gag layers inherit, and the keys `Common.MakeItem` lists in its
`factionFilters`: `BaseMetal` for the plates, `DecorationMetal` for the trim, `Ball` for the ball
and its teeth, `Light` for the emissive bands. Recolouring a key repaints every layer using it.

# Variable: Heel

> `const` **Heel**: `string`

Defined in: src/FactionMachine/Futuristic/Limb/Boot.ts:20

The `Drone Heel` boot, registered in the `ItemBoots` group and tagged `Link.Socket.Ankle` so the
ankle link set can be anchored to it.

`heelpower: 2` doubles the heel level the game tolerates while it is worn, and `remove:
['Shoes']` clears the game's own `Shoes` outfit slot so the two cannot be worn together.
